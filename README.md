# 🚀 Madesh D — Portfolio

A modern, responsive personal portfolio website built with **HTML**, **CSS**, and **JavaScript**.

![Portfolio Preview](profile.jpg)

## ✨ Features

- 🌙 Sleek dark theme with glassmorphism design
- ✍️ Typewriter text animation
- 🎆 Interactive particle background canvas
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎯 Smooth scroll animations & hover effects
- 📂 Project showcase with GitHub links
- 📬 Contact section with email, phone & location

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- Vanilla JavaScript (Canvas API, Intersection Observer)
- Google Fonts (Inter, JetBrains Mono)

## 📁 Project Structure

```
portfolio/
├── index.html      # Main HTML structure
├── style.css       # Styling & responsive design
├── script.js       # Animations & interactivity
├── profile.jpg     # Profile avatar image
└── README.md       # This file
```

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Madesh-D/Digital--portfolio.git
   ```
2. Open `index.html` in your browser.

That's it! No build tools or dependencies required.
